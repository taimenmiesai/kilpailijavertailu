# Kilpailijavertailu

Esimerkki kilpailijaseurannasta. Kaikki kaupat (Kilpailija A, B ja C), tuotteet, hinnat, kampanjat ja kuvat ovat keksittyjä.

- Etusivujen havainnekuvat (`kuvat/`)
- Analyysi etusivujen kampanjoista
- Hintavertailu etusivuilla nostetuista tuotteista

## Sivut

| Sivu | Sisältö |
|---|---|
| `index.html` | Etusivu: yhteenveto ja linkit osioihin |
| `hypoteesi.html` | Hypoteesit ja mittarit |
| `kehitysideat.html` | Kehitysideat ja toteutuksen vaatimukset |
| `kilpailijat.html` | Kilpailijat, linkit kilpailijasivuille |
| `kilpailija-a.html`, `kilpailija-b.html`, `kilpailija-c.html` | Havainnekuvat ja kampanja-analyysi |
| `hintavertailu.html` | Hintavertailu ja hintahistoria |
| `kampanja-arkisto.html` | Kampanja-arkisto: kalenteri ja lista |
| `menetelma.html` | Menetelmä ja rajoitukset |

Yhteiset tiedostot: `assets/style.css` (tyylit), `assets/site.js` (valikko, kuvien suurennus), `assets/kalenteri.js` ja `assets/hintahistoria.js`.

Sivusto: https://taimenmiesai.github.io/kilpailijavertailu/
